# P0-1 商店重構報告

## 目標
- 將商店改為「左欄分類 / 中欄列表 / 右欄詳情 / 底部結算條」。
- 提升橫向手機操作可讀性，降低誤觸與資訊混亂。

## 變更內容
- 重寫商店 UI 流程：`src/ui/ShopPanel.ts`
  - 新增模式狀態：`_selectedBuyId`、`_selectedSellId`。
  - 列表只負責選擇，購買/出售在右欄詳情區統一確認。
  - 底部固定結算條顯示「本次交易摘要 + 目前金幣」。
  - 將道具類型轉為玩家語言（裝備/消耗品/材料/蛋/配方/任務道具）。
- 追加商店版型樣式：`index.html`
  - `shop-content` 雙欄布局。
  - `shop-detail` 詳情卡與 `shop-bottom-bar` 固定結算條。
  - `shop-list-row.is-selected` 明確選中態。
  - 手機橫向斷點下自動壓縮為單欄 + 詳情區高度限制。

## 驗證
- `npm run -s typecheck`：通過
- `npm run -s build`：通過

## 使用邏輯
- 購買：左側分類 -> 中欄選物 -> 右欄調數量 -> 右欄確認。
- 出售：中欄選物 -> 右欄調數量 -> 右欄確認。

## 已知限制
- 現階段仍沿用現有商店資料分類規則（由 RuntimeEconomySource 的名稱/類型推斷）。
- 未新增全文搜尋與排序（下一版可加）。
